# Pure CSS Day & Night Scene

An interactive day and night scene built with **zero JavaScript**, using only HTML and CSS.

## Live Demo
https://un-project.vercel.app

## Features
- Toggle switch changes the scene from day to night
- Smooth sky colour transition
- Moving clouds, swaying tree, twinkling stars and fireflies
- Responsive on mobile and desktop
- Supports reduced-motion preference

## Tech Stack
- HTML5
- CSS3 (Custom Properties, @property, :has(), Keyframes, checkbox hack)

## How to Run
1. Download or clone this repo
2. Open `index.html` in any browser
